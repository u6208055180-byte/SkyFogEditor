# Sky & Fog Editor — Fabric 1.21.11

Клієнтський мод для зміни кольору неба й туману. Налаштування зберігаються в `config/skyfog-editor.json`.

## Керування
- `O` — відкрити меню.
- Кнопка «Небо» перемикає кольорові пресети неба.
- Кнопка «Туман» перемикає кольорові пресети туману.
- Повзунок змінює силу кольорового тону туману.
- «Ефекти» вмикає/вимикає зміни.

Зміни локальні: інші гравці їх не бачать.

## Збірка
Потрібні JDK 21 та Gradle, сумісний із Fabric Loom 1.14.
У теці проєкту виконай:

```bash
gradle build
```

Готовий мод буде в `build/libs/skyfog-editor-1.0.0.jar`.

## Встановлення
1. Збери мод командою вище.
2. Перемісти JAR у папку `.minecraft/mods`.
3. Переконайся, що встановлені Fabric Loader і Fabric API для Minecraft 1.21.11.

## Примітка
Це вихідний проєкт. У цьому середовищі не було доступного Gradle, тому JAR тут не збирався і сумісність конкретного запуску не була перевірена. Якщо Gradle повідомить про помилку API після оновлення Minecraft, перевір повідомлення компілятора й актуальні версії Fabric.
